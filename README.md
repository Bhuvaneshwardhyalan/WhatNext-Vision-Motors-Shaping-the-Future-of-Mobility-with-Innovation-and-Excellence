# WhatNext-Vision-Motors-Shaping-the-Future-of-Mobility-with-Innovation-and-Excellence

Features
Automated Dealer Assignment – Assigns the most suitable dealer based on customer location
Real-Time Inventory Tracking – Maintains up-to-date vehicle stock across dealers
Order Management System – Manages bookings, order status, and history
Test Drive Scheduling – Enables customers to book and manage test drives
Automated Notifications – Sends updates for orders and appointments
Customer Management – Stores and tracks customer information and interactions
