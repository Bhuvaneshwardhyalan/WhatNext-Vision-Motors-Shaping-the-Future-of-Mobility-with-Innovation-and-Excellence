# WhatNext-Vision-Motors-Shaping-the-Future-of-Mobility-with-Innovation-and-Excellence
 WhatNext Vision Motors is a Salesforce-based project that streamlines vehicle order management by automating dealer assignment and tracking inventory in real time. It enhances customer engagement and improves efficiency in automotive retail through smart automation and scalable solutions.
 
Features
Automated Dealer Assignment – Assigns the most suitable dealer based on customer location
Real-Time Inventory Tracking – Maintains up-to-date vehicle stock across dealers
Order Management System – Manages bookings, order status, and history
Test Drive Scheduling – Enables customers to book and manage test drives
Automated Notifications – Sends updates for orders and appointments
Customer Management – Stores and tracks customer information and interactions

Technologies Used 
Salesforce CRM
Flow Bulider
Apex Trigger

Modules
User Management Module – Handles customer, dealer, and admin profiles with role-based access
Vehicle Management Module – Manages vehicle details, specifications, and availability
Inventory Management Module – Tracks stock levels across different dealers in real time
Order Management Module – Processes vehicle bookings, order status, and history
Dealer Management Module – Maintains dealer information and automates dealer assignment
Test Drive Management Module – Schedules and manages test drive requests
Notification Module – Sends alerts and updates to customers and dealers
Reporting and Analytics Module – Generates reports for sales, inventory, and performance insights
Workflow Automation Module – Automates processes using Salesforce Flow and Apex
